## Formato Geral

```
SOBRENOME, Nome. Titulo da obra. Edicao. Local: Editora, Ano.
```

## Formatos por Tipo de Fonte

### Livro

```
SOBRENOME, Nome. Titulo do Livro. ed. Local: Editora, Ano.
```

**Exemplo:**
```
MORIM, Eduardo. Introducao a Sistemas Microcontroladores. 3. ed. Sao Paulo: Editora Tecnica, 2020.
```

### Artigo em Periodico

```
SOBRENOME, Nome. Titulo do Artigo. Nome do Periodico, Local, v. Numero, n. Numero, p. Paginas, Ano.
```

**Exemplo:**
```
SILVA, Joao; SANTOS, Maria. IoT com ESP32. Revista de Eletronica, Sao Paulo, v. 15, n. 3, p. 45-52, 2021.
```

### Trabalho em Congresso

```
SOBRENOME, Nome. Titulo do Trabalho. In: NOME DO CONGRESSO, Ano, Local. Anais... Local: Editora, Ano. p. Paginas.
```

**Exemplo:**
```
PEREIRA, Ana. React para IoT. In: SIMPOSIO DE ELETRONICA, 2022, Campinas. Anais... Campinas: Editora Unicamp, 2022. p. 123-130.
```

### Pagina Web

```
SOBRENOME, Nome. Titulo do Conteudo. Disponivel em: URL. Acesso em: Dia mes. Ano.
```

**Exemplo:**
```
ESPRESSIF. ESP32 Technical Reference Manual. Disponivel em: https://www.espressif.com. Acesso em: 15 jan. 2023.
```

### Documento Tecnico

```
ORGANIZACAO. Titulo do Documento. Versao. Local: Organizacao, Ano.
```

**Exemplo:**
```
REACT. Documentacao Oficial do React. v. 18.0. Disponivel em: https://reactjs.org. Acesso em: 10 fev. 2023.
```

## Instrucoes

- Listar em ordem alfabetica pelo sobrenome do primeiro autor
- Cada referencia em paragrafo hanging (primeira linha alinhada, subsequentes recuadas)
- Separar autores com ponto e virgula
- Usar "E" antes do ultimo autor
- Incluir DOI quando disponivel
- Total: 1 pagina por 15-20 referencias
